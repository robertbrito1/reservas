# 🍽️ Sistema de Gestión de Reservas

[![Live Demo](https://img.shields.io/badge/Acceder_al_Sistema-Verde?style=for-the-badge&logo=django)](https://reservas-flax-nine.vercel.app/accounts/login/?next=/)
[![Django](https://img.shields.io/badge/Django-092E20?style=for-the-badge&logo=django&logoColor=white)](https://www.djangoproject.com/)

Plataforma profesional diseñada y desarrollada para la gestión eficiente de reservas en el sector gastronómico. Esta aplicación ha sido implementada en entornos reales de trabajo, optimizando el flujo operativo y mejorando la atención al cliente.

## 🚀 ¿Qué hace este sistema?
El sistema centraliza toda la gestión de un restaurante en una interfaz web intuitiva, permitiendo:

*   **Control de Reservas:** Registro, edición y seguimiento completo de cada cliente.
*   **Gestión de Espacios:** Asignación inteligente de mesas y turnos (día/noche), eliminando errores de organización.
*   **Registro Detallado:** Captura de datos esenciales (nombre, contacto) y comentarios especiales para una atención personalizada.
*   **Generación de Reportes:** Creación automática de documentos PDF para facilitar cierres de jornada y auditorías.
*   **Panel Administrativo:** Interfaz privada para la gestión avanzada de datos y usuarios del establecimiento.

## 💡 Valor Agregado
Este proyecto nació de una necesidad real. Al migrar procesos manuales a este sistema digital, se han logrado resultados tangibles:
*   **Reducción de tiempos:** Mayor agilidad en la toma y modificación de reservas.
*   **Precisión:** Eliminación de errores humanos en la ocupación de mesas.
*   **Historial:** Seguimiento claro de la afluencia de clientes para la toma de decisiones.

## 🛠 Tecnologías
*   **Backend:** Desarrollo robusto y seguro utilizando **Django (Python)**.
*   **Base de Datos:** Estructura optimizada para la gestión de datos críticos.
*   **Despliegue:** Sistema escalable desplegado en la nube para garantizar alta disponibilidad.
